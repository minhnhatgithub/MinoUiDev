HAtxLib C# Usage Guide

Use the generated XPaths from this inspector directly in your C# code using HAtxLib.

using HAtxLib; using HAtxLib.UIAutomator; // 1. Kết nối với thiết bị (Connect) HAtx atx = new HAtx("SERIAL_DEVICE", true); // 2. Tìm phần tử bằng XPath và Click atx.Node(By.Xpath("//*[@text='Bộ sưu tập']")).Click(); // 3. Kiểm tra phần tử có tồn tại hay không (Exists) bool isExist = atx.Node(By.Xpath("//*[@text='Bộ sưu tập']")).Exists(); // 4. Lấy Text và các thuộc tính (Attributes) của phần tử NodeObj info = atx.Node(By.Xpath("//*[@resource-id='com.example:id/title']")).Info; string text = info.Text; string className = info.ClassName; string contentDesc = info.ContentDescription; string resourceId = info.ResourceName; bool isClickable = info.Clickable; var bounds = info.Bound; // Lấy tọa độ (bounds) của phần tử

Hướng dẫn sử dụng (MinouiDev)

Công cụ Ping tọa độ

  • Thêm Ping: Giữ Ctrl + P và Click chuột trái vào vị trí bất kỳ trên điện thoại.
  • Xóa một Ping: Click đúp chuột vào biểu tượng Ping muốn xóa.
  • Xóa toàn bộ Ping: Nhấn phím Esc hoặc click vào nút Thùng rác ở thanh Footer.

Thao tác nâng cao

  • Click chuẩn xác: Di chuột qua cây thư mục (Hierarchy) bên phải, hệ thống sẽ tự động vẽ viền đỏ chỉ vị trí UI trên thiết bị.
  • Menu chức năng: Bấm chuột phải vào một khung UI bất kỳ trên điện thoại để hiện Menu Copy XPath hoặc Tap Element.
  • Làm mới (Refresh): Nhấn phím F5 để tải lại giao diện thiết bị.
