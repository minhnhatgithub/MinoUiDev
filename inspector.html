Hướng dẫn nhanh HAtxLib C#

Tất cả những gì bạn cần để tự động hóa UI Android trực tiếp từ C# bằng XPath tạo bởi Minoui.

Tăng tốc quá trình tự động hóa

HAtxLib cho phép bạn tương tác trực tiếp với các thành phần Android. Chỉ cần click, copy XPath từ Minoui và dán vào script C# của bạn.

1. Kết nối thiết bị
Thiết lập một kết nối ổn định thông qua ADB.
2. Tìm phần tử
Sử dụng các XPath mạnh mẽ để tìm kiếm đối tượng một cách chính xác.
3. Thao tác & Kiểm tra
Thực hiện click, vuốt, nhập chữ và kiểm tra các trạng thái.
Example.cs 
using HAtxLib;
using HAtxLib.UIAutomator;

// Kết nối thiết bị
HAtx atx = new HAtx("SERIAL_DEVICE", true);

// Tìm phần tử và click
atx.Node(By.Xpath("//*[@text='Bộ sưu tập']")).Click();

// Kiểm tra phần tử có tồn tại hay không
bool isExist = atx.Node(By.Xpath("//*[@text='Bộ sưu tập']")).Exists();

// Lấy thông tin thuộc tính
NodeObj info = atx.Node(By.Xpath("//*[@resource-id='com.example:id/title']")).Info;
string text = info.Text;
bool isClickable = info.Clickable;

// Các thao tác cơ bản
atx.Click(500f, 800f); 
atx.Swipe(500f, 1500f, 500f, 500f, 500); 
atx.ImeInputText("Xin chào Việt Nam", clear: true); 

// Điều khiển hệ thống
atx.Press(HAtx.PressKey.Home); 
atx.AppStart("com.android.settings");

Hướng dẫn sử dụng (MinouiDev)

Công cụ Ping tọa độ

  • Thêm Ping: Giữ Ctrl + P và Click chuột trái vào vị trí bất kỳ trên điện thoại.
  • Xóa một Ping: Click đúp chuột vào biểu tượng Ping muốn xóa.
  • Xóa toàn bộ Ping: Nhấn phím Esc hoặc click vào nút Thùng rác ở thanh Footer.

Thao tác nâng cao

  • Click chuẩn xác: Di chuột qua cây thư mục (Hierarchy) bên phải, hệ thống sẽ tự động vẽ viền đỏ chỉ vị trí UI trên thiết bị.
  • Menu chức năng: Bấm chuột phải vào một khung UI bất kỳ trên điện thoại để hiện Menu Copy XPath hoặc Tap Element.
  • Làm mới (Refresh): Nhấn phím F5 để tải lại giao diện thiết bị.
